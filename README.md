# [El Club de la Papa Frita App / Proyecto de Tesis] 📱🎮

Una aplicación móvil 2D desarrollada en Unity con integración a Firebase, diseñada con un objetivo comercial real: gamificar la experiencia en un bar/local gastronómico para fomentar el consumo durante los días de menor tráfico.

**Tecnologías utilizadas:** Unity, C#, Firebase (Realtime Database / Authentication), UI/UX adaptativo.

## 💻 Mi Rol en el Proyecto (Desarrollador Principal)

Fui responsable del **100% de la programación, arquitectura y lógica técnica** de la aplicación, trabajando bajo metodologías de resolución de problemas desde cero hasta el producto final. 

**Responsabilidades clave:**
* **Arquitectura de Código (C#):** Diseño y programación completa de la lógica de los minijuegos (Tanda de Penales y Ludo), manejando físicas 2D, estados del juego y detección de inputs en pantallas táctiles.
* **Integración Backend:** Implementación de **Firebase** para gestionar el progreso de los usuarios, guardado de datos y actualización de puntuaciones en la nube de forma segura.
* **Desarrollo de UI:** Construcción y programación de toda la interfaz gráfica de usuario (menús, HUD, pantallas de carga), optimizada para resoluciones móviles.
* **Optimización Comercial:** Traducción de una necesidad comercial (retención de clientes en un bar) en mecánicas de juego funcionales (sistema de recompensas mediante puntajes).

> *Nota: Por motivos de seguridad y confidencialidad comercial (credenciales de base de datos), el código fuente de este proyecto se mantiene en un repositorio privado. El presente repositorio funciona como demostración de las mecánicas y la arquitectura desarrollada.*
